# 🎬 Movie Recommendation System (Content-Based)

A **content-based movie recommender system** built using the **TMDB 5000 Movies Dataset**.  
The system recommends movies based on **semantic similarity** between movie metadata such as genres, keywords, cast, crew, and overview.

---

## 📌 Project Overview

Traditional recommendation systems often rely on user ratings.  
This project instead focuses on **content-based filtering**, where recommendations are generated by comparing movie features using **Natural Language Processing (NLP)** techniques.

Key idea:
> *Movies with similar content → similar recommendations*

---

## 🧠 Approach & Methodology

### 1. Data Sources
- `tmdb_5000_movies.csv`
- `tmdb_5000_credits.csv`

### 2. Feature Engineering
The following attributes are combined into a single **tags** column:
- Genres
- Keywords
- Cast (top actors)
- Crew (director)
- Movie overview

### 3. Text Vectorization
- **CountVectorizer** is used to convert text into numerical vectors
- Stop words are removed
- Vocabulary size is limited for efficiency

### 4. Similarity Computation
- **Cosine Similarity** is computed between movie vectors
- Movies with higher similarity scores are considered more relevant

## 📈 Model Evaluation (Important)

This is a **content-based, unsupervised recommendation system**, therefore:

❌ **Accuracy, Precision, Recall (classification metrics) are NOT applicable**

Instead, performance is evaluated using **ranking and similarity-based metrics**.

### ✅ Evaluation Metrics Used

1. **Precision@K**
   - Measures how many of the top-K recommendations are relevant
   - Relevance is defined using **genre overlap**

2. **Genre Overlap Score**
   - Measures semantic similarity between query movie and recommendations
   - Score range: `0 → 1`

3. **Hit Rate**
   - Checks whether at least one relevant movie appears in recommendations

📌 These metrics provide **quantitative justification** for recommendation quality.

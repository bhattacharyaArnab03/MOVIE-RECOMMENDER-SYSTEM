# 🎬 Movie Recommendation System (Content-Based)

A **Content-Based Movie Recommendation System** built using the **TMDB 5000 Movies Dataset**.
The system recommends movies by analyzing **semantic similarity between movie metadata** such as genres, keywords, cast, crew, and overview using **Natural Language Processing (NLP)** techniques.

Instead of relying on user ratings, this system focuses on **movie content similarity** to generate recommendations.

---

# 📌 Project Overview

Traditional recommendation systems often depend on **user ratings and collaborative filtering**.
However, in many cases ratings may not be available.

This project implements **Content-Based Filtering**, where recommendations are generated by comparing movie attributes.

### Core Idea

> Movies with similar content → Similar recommendations

Example:

```
Query Movie: Avatar

Recommended Movies:
• Aliens
• Guardians of the Galaxy
• John Carter
• Star Trek
• Oblivion
```

---

# 🧠 Approach & Methodology

## 1. Data Sources

The project uses the **TMDB 5000 Movies Dataset**, consisting of two datasets:

* `tmdb_5000_movies.csv`
* `tmdb_5000_credits.csv`

These datasets contain metadata including:

* Movie titles
* Genres
* Keywords
* Cast
* Crew
* Plot overview

---

## 2. Data Preprocessing

The following preprocessing steps are applied:

1. Merge the **movies** and **credits** datasets using the movie title.
2. Extract important features:

   * genres
   * keywords
   * cast (top actors)
   * crew (director)
   * overview
3. Convert JSON-like columns into usable lists.
4. Combine all features into a single column called **tags**.

Example:

```
tags = genres + keywords + cast + director + overview
```

This `tags` column represents the **content description of a movie**.

---

## 3. Text Vectorization

To compare movies mathematically, text data must be converted into vectors.

This project uses:

**CountVectorizer (Scikit-Learn)**

Features:

* Converts text into numerical vectors
* Removes stopwords
* Limits vocabulary size for efficiency

Example transformation:

```
tags → numerical vector representation
```

---

## 4. Similarity Computation

After vectorization, similarity between movies is computed using:

**Cosine Similarity**

Cosine similarity measures the angle between vectors.

```
similarity(movieA, movieB)
```

Higher similarity score → more relevant recommendation.

The result is stored as a **similarity matrix**.

# 📈 Model Evaluation (Important)

This project implements an **unsupervised recommendation system**, so traditional classification metrics such as:

* Accuracy
* Precision
* Recall
* F1-score

are **not applicable**.

Instead, evaluation is based on **ranking quality and semantic similarity**.

### Metrics Used

### 1️⃣ Precision@K

Measures how many of the **top K recommendations are relevant**.

Relevance is determined using **genre overlap**.

Example:

```
Precision@5 = 0.8
```

Meaning 4 out of the top 5 recommendations are relevant.

---

### 2️⃣ Genre Overlap Score

Measures similarity between genres of the query movie and recommended movies.

Range:

```
0 → no similarity
1 → identical genres
```

Example:

```
[0.66, 0.66, 0.33, 0.66, 0.33]
```

---

### 3️⃣ Hit Rate

Checks whether **at least one relevant movie appears in the top recommendations**.

```
Hit Rate = 1
```

Meaning at least one correct recommendation exists.
